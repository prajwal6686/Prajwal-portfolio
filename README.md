## About the Project

This portfolio was designed and developed to present my marketing experience through an interactive, single-page website.

Rather than simply listing skills and responsibilities, it highlights the projects I've worked on, the problems I've addressed, and the results I've contributed to.

The experience combines editorial-style typography, visual storytelling, scroll-based animations, and interactive project presentations.

## Run Locally

This is a static website and does not require a build process or package installation.

**Option 1 — Open directly**

Open `index.html` in your browser.

**Option 2 — Run a local server**

```bash
python -m http.server 8080
```

Visit:

```text
http://localhost:8080
```
