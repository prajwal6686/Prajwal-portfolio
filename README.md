## 🚀 How to Run Locally

### Option 1: Double Click
Simply open `index.html` in any modern web browser (Google Chrome, Edge, Safari, Firefox). No build tools, NodeJS, or dependencies required!

### Option 2: Local HTTP Server (Recommended)
From PowerShell or terminal in this folder:
```powershell
python -m http.server 8080
```
Then open: [http://localhost:8080](http://localhost:8080)

---

## 🌐 Deploy to Netlify

### Drag and Drop (Fastest):
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop the `prajwal-portfolio` folder.
3. Your site is live instantly!

### Netlify CLI:
```bash
npm install -g netlify-cli
netlify deploy --prod --dir=.
```
